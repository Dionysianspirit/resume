## 项目经历

### 「径舟」——面向学生的 AI 轻量级学习工具

独立开发 · 2026 · 开源：[Dionysianspirit/jingzhou](https://github.com/Dionysianspirit/jingzhou)

- **定位**：针对学生「预习 – 练习 – 温故」场景，参考公开产品 ima 与 NotebookLM 后，确定「聚焦学习场景做轻」；独立规划知识库 Agent（RAG）方案。
- **实现**：前端用 Kimi Code 约 4 天迭代 3 版，后端用 Cursor 约 3 天迭代 2 版；一周完成从 0 到 1。架构为本地小模型语义召回 + 云端大模型生成；支持资料导入、个人知识库，覆盖预习 / 练习 / 复习。
- **验证**：两个班级课堂演示，82 名同学试用，回收 39 条反馈（口头 20、留言 15、建议 4）。针对「功能重叠」反馈做出「识海偏误图」（记录做题犹豫并给出原因分析）。8 名同学持续使用。
- **结果**：中软国际「卓越杯」AI 挑战赛省级二等奖（397 支队伍第 93）。赛后补上向量持久化与可解释检索并开源。
